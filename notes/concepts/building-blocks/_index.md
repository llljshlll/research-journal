# Building Blocks

모델을 구성하는 재사용 부품. "이 블록을 왜 쓰는지, 원리가 뭔지"를 정리한다.

- [[linear]]: 차원 변환, projection
- [[transformer-block]]: attention + MLP + residual + norm
- [[patchify-flatten]]: 공간축을 토큰 시퀀스로 펼치기
- [[normalization]]: LayerNorm, GroupNorm, AdaLN
- [[conv-vs-attention]]: 로컬 고정 가중치 vs 전역 동적 가중치

관련: [[attention]], [[vae]]

# TRELLIS.2 semantic 조건 주입 reference

## 배경

치아 mesh에 TRELLIS.2를 적용해 보면, 생성된 텍스처의 segmentation은 vertex의 semantic label이 아니라 모델의 prior에 의존함. 그래서 일부 치아에서 semantic이 다르게 생성됨.

현재 상황:
- **semantic label 있음**: mesh vertex마다 잇몸인지, 몇 번 치아인지 명시적인 label이 있음
- **GT 텍스처 없음**: 학습에 쓸 정답 텍스처가 없음
- **도메인 한정**: 치아

목표는 semantic label을 기존 ControlNet 방식으로 TRELLIS.2에 주입해 학습시키는 것임. 단, GT 없이 학습해야 하므로 이때 참고할 만한 reference를 조사함.


## 1. Direct Preference Optimization (DPO) 방식

### SAM 3D: 3Dfy Anything in Images (Meta, CVPR 2026)
- **참고 위치**: Appendix의 Algorithm 1 — SAM 3D Basic Alignment (Texture, Shape)
- **목적**: 사진 속 물체에 대해 여러 3D 후보를 만들고, 사람이 사진과 더 잘 맞는다고 선택한 후보를 이용해 3D 생성 모델을 개선, 후학습에서 쓰임
- **흐름**: ① 사람이 3D 후보 비교 → ② 선택된 후보로 지도 미세조정(SFT) → ③ 선택·탈락 후보 쌍으로 선호 학습

#### 1. 후보 생성
1. **여러 후보 생성**: 같은 입력에서 여러 후보를 생성함. 본문에서는 물체 하나당 후보 8개를 비교하는 방식으로 설명함.
2. **두 후보씩 비교**: 평가자가 원본 이미지를 참고해 두 3D 후보를 회전·확대하면서 왼쪽 우세 / 오른쪽 우세 / 동등 중 하나를 선택함. 우세한 후보를 남기고 탈락 후보를 다음 후보로 교체하며, 동등이면 무작위로 하나를 남김.
3. **최종 승자의 품질 확인**: 모든 후보를 비교한 뒤, 마지막에 남은 후보가 학습에 사용할 만큼 좋은지 별도로 평가함. 모든 후보가 나쁜 경우에도 상대적 1등은 생기기 때문에, 최종 승자가 품질 기준을 통과한 경우에만 선호 샘플 x_w로 채택함.
4. **DPO용 쌍 구성**: 채택된 승자와 탈락 후보를 짝지어 (x_w, x_l)을 구성함.

#### 2. SFT — 사람이 고른 후보 자체를 학습
품질 기준을 통과한 승자 x_w를 학습 타깃으로 사용함. Shape 모델은 선택된 형상을, texture 모델은 선택된 텍스처를 생성하는 방향으로 flow matching 학습을 수행함. 이 단계에서 사용하는 정보는 "**이 입력에 대해 이 결과가 좋은 예시**"라는 것임.

#### 3. DPO — 승자와 패자의 차이를 학습
1. **후보별 velocity 예측**: 승자와 패자 각각의 noisy latent에 대해, 학습 모델과 고정된 SFT 기준 모델이 각각 velocity를 예측함.
2. **후보별 오차 계산**: 각 모델의 예측을 해당 후보의 flow matching 목표 velocity와 비교함. 따라서 승자와 패자 각각에 대해 기준 모델 오차와 학습 모델 오차를 얻음.
3. **승자 쪽의 상대적 개선량을 높이도록 업데이트**: 후보 하나의 개선량을 I(x)=E_ref(x)-E_train(x)로 두면, DPO는 I(x_w)-I(x_l)이 커지도록 학습함.

즉, 사람이 같은 물체에서 texture A를 B보다 선호했다면, SFT 모델 대비 A의 velocity 예측 개선량이 B의 개선량보다 커지도록 Texture & Refinement 모델을 업데이트하는 방식임.

#### 우리 논문에 적용할 여지
**실제 vertex label을 후보 선택 기준으로 쓰기**
- 동일 mesh와 동일 reference image를 고정하고 seed만 바꿔 텍스처 후보를 생성한 뒤, 각 후보의 렌더링에 실제 치아·잇몸 경계선을 겹쳐 봄
- → 정답 RGB 없이도 어느 후보에서 잇몸색이 실제 경계를 넘어갔는지 판단할 수 있음


### Flow-DPO (Improving Video Generation with Human Feedback, NeurIPS 2025)
**목적**: 같은 프롬프트에서 사람이 어떤 영상을 더 선호하는지 학습해서, 사전학습된 비디오 생성 모델의 출력을 개선함

| 모델 | 구성 | 역할 |
|---|---|---|
| **기준 모델** | 원래의 비디오 생성 base model | LoRA 적용 전 예측 오차 측정. 가중치 고정 |
| **학습 모델** | 동일한 base model + LoRA | LoRA 적용 후 예측 오차 측정. LoRA 가중치만 업데이트 |

| 단계 | 학습 대상 | 학습 목표 |
|---|---|---|
| **1단계 · VideoReward 학습** | 사전학습된 **Qwen2-VL-2B 기반 평가 모델** | 사람이 어떤 영상을 더 선호하는지 예측 |
| **2단계 · Flow-DPO 학습** | 사전학습된 **비디오 생성 모델에 추가한 LoRA** | VideoReward가 선호한 영상 쪽으로 생성 모델의 예측을 조정 |

#### 1. VideoReward 학습과 영상 순위 결정
1. **영상 쌍 구성**: 같은 프롬프트로 서로 다른 생성 모델이 만든 영상 A와 B를 한 쌍으로 구성함.
2. **사람의 선호 수집**: 전문 평가자가 두 영상을 보고 시각 품질(VQ), 움직임 품질(MQ), 텍스트 일치도(TA) 각각에 대해 A 우세 / 동률 / B 우세 중 하나를 선택함. 영상 쌍 하나당 선호 label 3개를 수집함.
3. **VideoReward 학습**: 사람의 선호 label로 Qwen2-VL-2B 기반 평가 모델을 학습함. 학습 결과인 VideoReward는 프롬프트와 영상 하나를 입력받아 세 기준의 점수를 출력함.
4. **Flow-DPO용 승자·패자 결정**: 학습된 VideoReward로 A와 B를 각각 채점함. 세 기준을 함께 사용하는 실험에서는 영상별 세 점수의 산술평균을 비교해, 평균이 높은 영상을 선호 영상 x_w로, 낮은 영상을 비선호 영상 x_l로 지정함.

이렇게 얻은 (프롬프트, 선호 영상, 비선호 영상) 한 쌍이 Flow-DPO의 학습 데이터임. 이후 학습에는 어느 영상이 이겼는지만 사용하며, VideoReward의 점수 차이는 loss에 직접 넣지 않음.

#### 2. Flow-DPO 학습
원래 생성 모델과 비교했을 때, 선호 영상에서의 예측이 비선호 영상에서의 예측보다 상대적으로 더 개선되도록 LoRA를 학습함 (여기서 예측은 velocity 예측).

**① 영상마다 정답 velocity 생성**

영상 latent를 x, random noise를 ε이라고 하면, 둘을 섞은 모델 입력은 x_t=(1-t)x+tε임. 이 직선 경로에서 t가 변할 때 latent가 변하는 방향과 크기, 즉 정답 velocity는 v=ε-x임.

**② 각 모델의 예측을 같은 정답과 비교**

영상 하나에 대해 기준 모델과 학습 모델에 같은 입력을 주고, 각 모델이 그 영상의 정답 velocity를 얼마나 정확히 맞혔는지 측정함.

### Mesh-RFT(Enhancing Mesh Generation via Fine-grained Reinforcement Fine-Tuning, NeurIPS 2025)
Mesh DPO
같은 point cloud에서 생성한 두 mesh를 비교하되, 선호 mesh의 좋은 면과 비선호 mesh의 나쁜 면에 해당하는 토큰만 손실에 반영하는 후학습 방법
1. 같은 point cloud에서 선호 쌍 구성
사전학습된 모델에 같은 point cloud P를 넣어 후보 mesh 8개를 생성. 가능한 28개 조합을 비교하고, 한쪽이 다음 세 지표 모두에서 엄격하게 우수한 경우에만 학습 쌍으로 채택
| 지표 | 선호 기준 | 측정 대상 |
|---|---|---|
| BER | 낮을수록 좋음 | 면 하나에만 연결된 경계 edge의 비율. 구멍이나 표면 단절을 파악하는 지표 |
| TS | 높을수록 좋음 | 삼각형들을 사각형으로 병합했을 때의 변환 비율과 사각형의 품질 |
| HD | 낮을수록 좋음 | 생성 mesh에서 샘플링한 점들과 입력 point cloud 사이의 기하학적 차이 |
지표 하나라도 동률이거나 우열이 엇갈리는 쌍은 제외

2. 선호 쌍의 각 mesh에 면별 마스크 생성
체적으로 더 좋은 M+에도 M-보다 품질이 낮은 부분이 존재. 그래서 전체 순위와 별도로 두 mesh의 삼각형 면을 각각 평가
- 각 삼각형이 사각형으로 병합되는지 확인
- 병합된 사각형의 내각이 90°에 가까운 정도, 변 길이 비율, 인접 사각형과의 비율 일관성을 평가
- 병합에 성공하고 품질 점수가 임계값을 넘으면 해당 삼각형에 1, 그 외에는 0을 부여

### ControlNet++
ControlNet++는 segmentation 조건을 반영하기 위해 segmentation loss를 사용함. segmentation loss는 생성 모델이 만든 결과 이미지를 segmentation 모델로 예측한 뒤, 그 예측과 GT segmentation의 차이를 loss로 줘서 학습하는 방식임.

**우리 방식에 적용**
- 우리 방식에도 이 loss를 추가함. 단, 우리는 2D 이미지가 아니라 복셀이므로, 렌더링한 이미지에서 비교해야 함.
- 6개 정도의 뷰에서 비교한 뒤 loss를 적용함 (뷰 개수와 시점은 ablation 필요)
